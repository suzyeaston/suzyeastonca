# Draft AI art records

Draft works live here so production `/ai-art/` stays empty until something is actually ready.

- Files in this folder are **never** rendered on the public gallery.
- Use them as fixtures while wiring import/validation.
- Promote a work by importing a publish bundle with `--apply`, or by moving a validated record into `../works.json` with `"status": "published"`.

See `docs/ai-art.md` for the full add-a-work path.
